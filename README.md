# Gemini Agent

**Name:** Sana

OpenAI Agents SDK running on Google Gemini through its OpenAI-compatible endpoint.

## How to run

1. Install uv: https://docs.astral.sh/uv/
2. Clone this repo and `cd` into it
3. Create a `.env` file with: `GEMINI_API_KEY=your_key_here`
4. Run:

   uv sync
   uv run main.py
